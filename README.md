# Esőerdő

Iskolai webfejlesztési projekt: interaktív, reszponzív weboldal az esőerdők világáról, élővilágáról, környezeti szerepéről és a fenntarthatóság fontosságáról.

## Technológiák

- HTML5, CSS3
- Bootstrap 5 (CDN)
- JavaScript
- Leaflet.js (később, a térképhez)
- GitHub + GitHub Pages, Trello

## Mappastruktúra

Esőerdő/
│
├── index.html
│
├── css/

│

│
├── img/
